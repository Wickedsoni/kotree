# 11 — Open checks (Phase 0 first)

> **Purpose:** one list of every open `⚠️ VERIFY` mark in docs 00-10, with the exact test, the phase it runs in, the pass criterion and the fallback.
> **Read this when:** starting Phase 0, or any phase that has rows below; after a check runs, to record the result.
> **Depends on:** `00-decisions.md` (wins conflicts), `01`, `02`, `03`, `04`, `05`, `06`, `07`, `09`, `10`.
> **Version:** v1 · 20 Oct 2026 · owner: `architect`. Built from `grep VERIFY docs/0*.md` on 20 Oct 2026.

How to use:
- Run the rows in table order. Within Phase 0, cheap checks and blockers come first.
- When a row is settled, write the result and date in the doc named in column 2, remove its `⚠️ VERIFY` there (that doc's owner does this), and add `DONE <date>` to the row here.
- Commands are POSIX shell (Git Bash on the author's Windows machine, or the Ubuntu CI runner). Paths are from the repo root unless the row says `/site`.
- If a fallback is applied, the owning doc changes first (ADR if it is a lasting decision), then the code.
